整理版里有什么

40 箱进口橙，一箱一行。南非、澳洲都有。每一行记的是那一箱箱面上印的东西：产地、出口商/包装厂、品牌、品种、箱型、规格计数、等级、PUC、果园号、PHC、GGN、冷库、批次、采后药剂处理，最后一格贴那一箱的箱标照片。

里面有几处我自己也拿不准的，照实记着，没有替它圆过去。表跟着文章一起看。

怎么填：拆箱时顺手拍四张

  1. 商业信息面整面——箱子摆正了拍，别歪着拍。这张用来看整张标签的版式和印字
  2. PUC / PHC 那一栏特写——字小，一定要凑近。果园号、包装厂号、冷库号都在这一带
  3. 侧面或顶面的日期、批次——装箱日期、Pack Ref、Batch 一般打在这里
  4. 规格计数那一栏——Count / Size，比如 4/56

四张照片，加一条到货日期，一箱货的可追溯信息就齐了。回到电脑上对着照片填，比对着箱子填快。

字段说明

整理版和空表是同一套列，下面这些格子都是指什么。

序号
自己按拆箱顺序编，一行一箱。
到货日期
货到市场那天，不是你拆箱那天。
产地国家
箱标 Origin。一般印国家名，如 SOUTH AFRICA。
出口商 / 包装厂
Brand/Mark 那一带，加箱子底部的出口商全称。贸易主体。同一家出口商可能对接好几家包装厂。
品牌
箱面印得最大的那个 logo。商业品牌，未必等于出口商名。
品种
Variety。如 Midknights、Witkrans Navelate。括号里的类型（Valencia / Navel）也记上。
品类
橙 / 柑 / 橘 / 葡萄柚 / 柠檬，自己归类。
包装箱型
Pack。如 A15C。
计数规格
Size / Count。如 4/56，写清楚是每箱几个。
等级
Class / Cat。Class 1、Class 2，或者混级时印的 COMPOSITE。
PUC
PUC 一栏。Production Unit Code，生产单位＝农场。南非 DALRRD 注册，一个码对一家。现在也在改叫 FBO 代码。
果园号
Orchard / Store。果园或库房的登记编号。
PHC / Depot
PHC / Depot 一栏。Packhouse Code，在哪儿包的。
GGN
GGN。GLOBALG.A.P. 认证编号。
冷库 / 仓储
Cooling Facility。存在哪个库。箱面印 Cooling Facility，南非官方登记体系里叫 CCS。
批次 / 日期编码
Batch / Pack Ref。包装批次和日期，照抄，别自己换算。
采后药剂处理
Treated with。照抄箱面原文，别省略成分名。
是否 Sunkist 贴牌
填 是 / 否。
备注
开箱当时的口感、硬度、损耗、异常，趁记得赶紧写。
标签图片
照片文件名，或者把图直接插到这一格。

品牌、出口商、品种这些，箱面印什么就填什么，不要自己改成中文名——回头对不上。

同一批货如果分了几箱抽检，每箱单独一行，不要合并。

拍完照当天就填。隔三天再看照片，很多当时一眼能认的东西就认不出了。

澳洲箱是另一套体系（包装厂号、包装棚号、种植者名），PUC / PHC 那几栏会空着，正常。
